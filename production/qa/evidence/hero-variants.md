# Ждан: 10 вариантов облика (на выбор)

Лист: `hero-variants-sheet.png`. Каждый вариант отдельно: `hero-variant-01.png` … `-10.png` (там же
проверка в игровом размере 160 px и силуэт 48 px). Как герои смотрятся на болоте: `hero-variants-onbg.png` (варианты 1, 4, 8, 10).

Техника: 2D без 3D-движка. Фигуры собраны из форм на Python (numpy + PIL): толстый тёмный контур
`#120D12` с переменной толщиной, плоская заливка в 3 ступени тени, мягкая живописная фактура,
тёплый контровой свет, отрисовка в 2x с уменьшением. Всё бесплатное.

Общее для всех: лицо и русая борода видны, красная нить Мокоши на запястье ближней руки,
деревянный оберег на шнурке светится, на 1-м ярусе палка. Пятый ярус у всех по библии (шишак
с бармицей, чешуйчатый доспех, корзно с золотой каймой, золотой оберег) плюс примета варианта.
