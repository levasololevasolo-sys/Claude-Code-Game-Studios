# Зоны тела врагов: рука и голова

> Статус: **[решение реализации 27.11, утвердить]**. Правила по ответам разработчика
> 27.11: руку рубит **только парирование** (`parry.md`), голову сносит только удар вниз
> в прыжке по голове врага, **который сейчас атакует**; у обычных врагов две смерти,
> обычная и с отлетающей частью; витязь и элиты только с 3-го раза; рука со щитом не
> рубится; награды за срез нет; у боссов зон нет. Числа временные.
>
> Код: `src/combat/limb_rules.gd` (правила), `src/enemies/enemy.gd` (срез на враге),
> `src/combat/limb_part.gd` (летящая часть), `src/combat/limb_mark.gd` (культя и надпись).
> Данные: `assets/data/limb_zones.json`, ручки `limb_*` и `death_sever_chance` в `assets/data/tuning.json`.

## 1. Обзор (Overview)

У обычных врагов есть зоны: тело, рука, которой враг бьёт, и голова. Руку отрубает
только парирование удара этой руки. Голову сносит только удар вниз в прыжке точно по
голове, пока враг замахивается или бьёт: удар наносит больше урона, голова летит и
ранит других врагов, а враг дерётся дальше без головы. Когда обычный враг умирает,
он умирает одним из двух способов: просто или с отлетающей головой или рукой.

## 2. Фантазия игрока (Player Fantasy)

«Поймал его удар и отсёк руку». «Прыгнул на него посреди замаха и снёс голову, голова
сбила второго». Срез не достаётся даром: только точный ответ на атаку врага. Это
бережёт баланс, руки и головы не летят от каждого удара.

## 3. Подробные правила (Detailed Rules)

### 3.1 Кто имеет зоны

| Враг | Рука (только парирование) | Голова (вниз в атаке) | Без руки |
|---|---|---|---|
| Аука (`ringer`) | да, лапа | да | толчок плечом: дальность ×0.6, урон ×0.65, появление ×1.5 |
| Упырь-щитник (`sentry`) | нет: рука со щитом не рубится, вторая рука только стреляет, а снаряды не парируются | да | |
| Навий витязь (`knight`) | да, копьё, с 3-го парирования | да, с 3-го удара | таран плечом: урон ×0.6, дальность ×0.6, замах ×1.35, выпад ×0.8 |
| Лешачонок (`rootling`) | нет | да | |
| Снежный волк, Трясинник (звери) | нет | только в смерти | |
| Нетопырь, Утопленник, Студёный дух, чучело, боссы | нет | нет | |

Элиты имеют зоны, пока `limb_elites` не 0, и им нужно `limb_elite_hits_needed` раз (§3.6).

### 3.2 Рука

1. Рука отлетает только от успешного парирования (`parry.md` §3.3), когда враг был в
   одном из состояний атаки (`attack_states`).
2. Обычный удар по руке (даже во время атаки) руку не рубит, урон обычный.
3. После среза: атака сорвана, оглушение, однорукие числа (F4), рука летит. Один раз.

### 3.3 Голова

1. Удар вниз, герой в воздухе, точка касания (F1) в зоне головы, враг в атаке.
2. Урон ×`limb_head_bonus`, голова летит и ранит других врагов (`limb_head_dmg`), пока
   не коснётся пола. Хозяина не ранит.
3. Без атаки тот же удар даёт обычный урон.
4. Потеря головы не убивает (F3). Безголовый бьёт мимо (F5), глаз и зоны головы нет.

### 3.4 Что видно и слышно

- Надписи «Без руки!», «Голова с плеч!», «Надруб 1/3».
- Летящая часть в цветах врага, брызги, навий туман; культя и шея с туманом.
- Отрубленное не рисуется; у спрайта щитника шейдер вырезает голову.
- Хит-стоп `limb_hitstop`, тряска `limb_shake`.
- Звуки (id, файлы делает другой агент, нет id = тишина): `limb_sever`, `limb_head_pop`, `limb_part_thud` (часть упала на пол).
- Сигнал `limb_severed(enemy, limb)` для художника.

### 3.5 Две смерти обычного врага

1. Обычная смерть.
2. Смерть со срезом: голова или рука отлетает как часть смерти (безвредно, без бонуса).
   Бывает, когда добивающий удар пришёл в зону головы или руки, или по шансу
   `death_sever_chance` (сначала голова, если её уже нет, рука).
3. Звери (волк, Трясинник) теряют голову только так.
4. Боссы и виды без строки в `limb_zones.json` всегда умирают обычно.

### 3.6 Витязь и элиты

Каждой конечности нужно `limb_elite_hits_needed` точных попаданий: парирований для руки,
ударов вниз в атаке для головы. Счёт свой у каждой конечности. До последнего надпись
«Надруб n/N», парирование при этом всё равно оглушает, удар вниз даёт обычный урон.

## 4. Формулы (Formulas)

**F1. Точка касания.** `S` прямоугольник удара, `T` силуэт врага (коробка урона + зоны),
`O = S ∩ T`, `d = limb_contact_depth` (6 px). Сбоку: `(ближний к герою край O ± d,
середина O по высоте)`; вниз: `(середина O по x, верх O + d)`; вверх: `(середина O по x,
низ O − d)`. Зона: голова, если `C` в ней, иначе рука, иначе тело. Зона в данных
`[x0, x1, y0, y1]`: `x` в долях ширины вперёд (зеркалится по взгляду), `y` в долях высоты вверх.

**F2. Урон удара по голове.** `урон = final(удар) × limb_head_bonus`. Пример: 11 × 2 = 22.
Парирование урона не наносит.

**F3.** `hp' = hp − урон`, смерть только при `hp' ≤ 0`.

**F4. Однорукие числа.** `stat'[k] = stat[k] × one_arm[k]`. Пример: дальность лапы 90 × 0.6 = 54.

**F5. Прицел безголового.** `x' = x_героя + limb_headless_err × sin(2π × limb_headless_freq × t)`.

**F6. Смерть со срезом.** Часть = зона удара (голова или рука, если на месте); иначе
если `бросок < death_sever_chance` (0.3): голова, если есть, иначе рука; иначе нет.

**F7. Счёт.** Срез на `n`-м точном попадании, `n = limb_elite_hits_needed` (3) для витязя и элит, иначе 1.

## 5. Крайние случаи (Edge Cases)

1. Удар по голове в атаке сам убивает: враг умирает, голова летит (и ранит других), второй части нет.
2. Второй срез той же части невозможен; удар по месту головы даёт обычный урон.
3. Парирование врага, который не атаковал (касание при ходьбе): только оглушение.
4. Парирование щитника: щит и рука на месте, только оглушение.
5. Аука «исчез» и Лешачонок под землёй ударов не получают.
6. Голова, коснувшись пола, больше не ранит; каждого врага ранит один раз.
7. Статусы, рывок, Вспышка, удары о стену голову не сносят, но могут убить: тогда
   смерть со срезом только по шансу.
8. Безголовый враг и элита «Морок»: телепорт работает, бьёт мимо.
9. Счёт «Надруба» не сбрасывается со временем.

## 6. Зависимости (Dependencies)

- Парирование (`parry.md`): единственный способ отрубить руку.
- Движение и бой героя (`movement-and-combat.md`): прямоугольники удара, удар вниз, хит-стоп.
- Враги и элиты (`enemies-and-elites.md`): состояния атак, элиты, боссы. Тот документ ссылается сюда.
- Оружие (`weapons-and-loot.md`): множитель урона оружия входит в F2.
- Звук: id выше. Художественный проход: сигнал `limb_severed`.

| `limb_elite_hits_needed` | 3 | 1–5 | точных попаданий для витязя и элит |

## 8. Критерии приёмки (Acceptance Criteria)

1. Парированный взмах Ауки рубит руку, дальность 90 → 54 (`--limb-check`).
2. Обычный удар по руке Ауки во время атаки: руки на месте, урон 11 (`--limb-check`).
3. Витязь: рука только с 3-го парирования (`--limb-check`, юнит-тест).
4. Удар вниз по голове вне атаки: урон 11, голова на месте; в атаке: урон 22, голова
   летит, враг жив, голова ранит чучело на 18 (`--limb-check`).
5. Две смерти волка: при шансе 0 и ударе в тело обычная, при шансе 1 с головой (`--limb-check`).
6. Щитник: парирование не трогает щитовую руку (юнит-тест).
7. Удар без среза не меняет урон: демо печатает `blade dealt [11.0, 11.0, 19.8]`.
8. Скриншоты `production/qa/evidence/limb-parry.png`, `limb-head.png`, `limb-death.png`.
