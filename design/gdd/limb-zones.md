# Зоны тела врагов: рука и голова

> Статус: **[решение реализации 27.11, утвердить]**. Толкование просьбы разработчика
> подтверждено 27.11: руку рубит удар во время атаки врага, голову сносит только удар
> вниз в прыжке, голова ранит других врагов, безголовый враг дерётся дальше, у боссов
> зон нет. Числа ниже временные, их надо проверить в игре.
>
> Код: `src/combat/limb_rules.gd` (правила), `src/enemies/enemy.gd` (срез на враге),
> `src/combat/limb_part.gd` (летящая часть), `src/combat/limb_mark.gd` (культя и надпись).
> Данные: `assets/data/limb_zones.json`, ручки `limb_*` в `assets/data/tuning.json`.

## 1. Обзор (Overview)

У обычных врагов, похожих на людей, есть три зоны: тело, рука, которой враг бьёт, и
голова. Если герой точно попал по руке, пока враг замахивается или бьёт, рука
отлетает: атака врага сорвана, а дальше он бьёт по-другому (слабее, ближе, медленнее).
Если герой в прыжке ударил вниз точно по голове, голова слетает с плеч: удар наносит
больше урона, а голова летит и ранит других врагов. Враг без головы не умирает от
этого и дерётся дальше, только бьёт мимо, пока у него не кончится здоровье.

## 2. Фантазия игрока (Player Fantasy)

«Я поймал его на замахе и отсёк руку». «Я прыгнул сверху и снёс ему голову, а голова
сбила второго». Игрок чувствует себя богатырём из былины: точный и смелый удар
вознаграждается сразу и заметно. Риск в том, что для отрубания руки надо бить в
момент чужой атаки, а не убегать от неё.

## 3. Подробные правила (Detailed Rules)

### 3.1 Кто имеет зоны

| Враг | Рука | Голова | Чем бьёт рукой | Однорукая атака |
|---|---|---|---|---|
| Аука (`ringer`) | да | да | длинная лапа, удар после появления | короткий толчок плечом: дальность ×0.6, урон ×0.65, появление ×1.5 |
| Упырь-щитник (`sentry`) | да (рука со щитом) | да | удар щитом, прицел | щита больше нет; удар без щита: урон ×0.6, дальность ×0.7, замах ×1.4 |
| Навий витязь (`knight`) | да (рука с копьём) | да | выпад копьём | таран плечом: урон ×0.6, дальность ×0.6, замах ×1.35, выпад ×0.8 |
| Лешачонок (`rootling`) | нет | да | | |
| Трясинник, Снежный волк, Нетопырь, Утопленник, Студёный дух, чучело | нет | нет | | |
| Боссы | никогда | никогда | | |

Элиты имеют зоны, пока ручка `limb_elites` не равна 0.

### 3.2 Рука

1. Удар героя попадает в зону руки (формула F1).
2. Враг в это время в одном из своих состояний атаки (`attack_states` в
   `limb_zones.json`: замах и сам удар).
3. Тогда рука отрублена: урон этого удара ×`limb_arm_bonus`, атака сорвана (враг
   оглушён на `limb_arm_stagger` с и потом решает заново, следующая атака не раньше
   `limb_arm_recover` с), его числа меняются на однорукие (F4).
4. Удар по зоне руки вне атаки считается обычным ударом по телу.
5. Руку можно отрубить один раз.

### 3.3 Голова

1. Удар вниз (`atk_dir == "down"`), герой в воздухе.
2. Точка касания лезвия (F1) в зоне головы.
3. Тогда голова слетает: урон ×`limb_head_bonus`, голова летит прочь от героя и
   ранит каждого другого врага на пути один раз (`limb_head_dmg`), пока не коснётся
   пола. Самого хозяина она не ранит.
4. Потеря головы сама не убивает. Враг умирает, только если урон удара исчерпал
   здоровье (F3).
5. Безголовый враг дерётся дальше: видит героя со сдвигом (F5), глаз у него нет, зоны
   головы больше нет.
6. Удар сбоку, удар вверх и удар вниз с земли голову не сносят.

### 3.4 Что видно и слышно

- Хит-стоп `limb_hitstop`, тряска `limb_shake`, кровавый всплеск.
- Над врагом надпись «Без руки!» или «Голова с плеч!» на `limb_word_time` с.
- Отрубленная часть летит (простая фигура в цветах врага) с брызгами и навьим
  туманом. Культя руки и шея с поднимающимся туманом остаются на враге.
- На рисованных кодом врагах рука и голова перестают рисоваться. На спрайтовых
  (Упырь-щитник) шейдер вырезает область головы или руки из листа.
- Звук: тяжёлый удар пониже (`hit_heavy`, тон ×0.75).
- Для будущей художественной версии: сигнал `limb_severed(enemy, limb)` на враге.
  Художник меняет `LimbPart` и `LimbMark` на настоящие вырезанные части.

## 4. Формулы (Formulas)

**F1. Точка касания.** `S` прямоугольник удара героя, `T` силуэт врага (его коробка
урона, объединённая с зонами), `O = S ∩ T`, `d = limb_contact_depth`.
- сбоку: `C = (ближний к герою край O ± d, середина O по высоте)`
- вниз: `C = (середина O по x, верх O + d)`
- вверх: `C = (середина O по x, низ O − d)`

Зона: голова, если `C` в зоне головы; иначе рука, если в зоне руки; иначе тело.
Зона в данных: `[x0, x1, y0, y1]`, `x` в долях ширины `w` вперёд от ног (зеркалится
по взгляду), `y` в долях высоты `h` вверх от ног.

**F2. Урон удара по части.** `урон = final(удар) × k`, где `k = limb_arm_bonus` (рука),
`limb_head_bonus` (голова), 1 для обычного удара. `final` это обычная формула
боя (movement-and-combat F6-F8). Пример: меч 11 × 1.5 = 16.5; вниз 11 × 2 = 22.

**F3. Здоровье после удара по голове.** `hp' = hp − урон`. Смерть только при `hp' ≤ 0`.

**F4. Однорукие числа.** Для каждого ключа `k` из `one_arm`: `stat'[k] = stat[k] × one_arm[k]`.

**F5. Прицел безголового.** `x' = x_героя + limb_headless_err × sin(2π × limb_headless_freq × t)`, `y' = y_героя`.

**F6. Вылет части.** `v = (±speed, −up)`, знак от героя прочь; рука `limb_arm_speed`,
`limb_arm_up`; голова `limb_head_speed`, `limb_head_up`. Урон головы другим:
`limb_head_dmg × множитель урона врага` (ярус и сложность).

## 5. Крайние случаи (Edge Cases)

1. Удар по голове, который сам убивает: враг умирает как обычно, голова всё равно летит.
2. Второй удар по уже отрубленной руке или по месту головы: обычный урон, ничего не летит
   (правило перепроверяется в `Enemy.hurt`).
3. Удар щитом заблокирован спереди (Упырь-щитник): рука всё равно рубится, если удар
   пришёлся на неё во время атаки, но урон снижен щитом, как обычно. После этого щита нет.
4. Аука в состоянии «исчез» не получает ударов, поэтому руку в этот миг не отрубить.
5. Лешачонок под землёй не получает ударов, голову можно снести только когда он снаружи.
6. Голова, коснувшись пола, больше не ранит. Каждого врага ранит не больше одного раза.
7. Статусы богов, рывок, Вспышка, удары о стену не рубят: только удар клинком (`STRIKE`).
8. Двуручный взмах (Коромысло) проверяет зону по тому прямоугольнику, который задел врага первым.
9. Безголовый враг и элита «Морок»: телепорт работает, но он бьёт по сдвинутой точке.
10. Отрубленная рука не меняет здоровье врага сверх бонуса удара.
11. Витязь без руки сохраняет щит и стойку, но в выпаде бьёт плечом.

## 6. Зависимости (Dependencies)

- Движение и бой героя (`movement-and-combat.md`): прямоугольники удара, удар вниз, хит-стоп.
- Враги и элиты (`enemies-and-elites.md`): состояния атак, элиты, боссы.
- Оружие (`weapons-and-loot.md`): множитель урона оружия входит в F2.
- Звук (`src/core/audio.gd`): звук среза.
- Будущий художественный проход: сигнал `limb_severed`.

## 7. Ручки настройки (Tuning Knobs)

В `assets/data/tuning.json`:

| Ручка | Значение | Что делает |
|---|---|---|
| `limb_arm_bonus` | 1.5 | множитель урона удара, отрубившего руку |
| `limb_head_bonus` | 2.0 | множитель урона удара, снёсшего голову |
| `limb_head_dmg` | 18 | урон летящей головы другим врагам |
| `limb_contact_depth` | 6 | глубина точки касания, px |
| `limb_elites` | 1 | 1: у элит есть зоны, 0: нет |
| `limb_hitstop` | 0.12 | хит-стоп среза, с |
| `limb_shake` | 9 | тряска |
| `limb_arm_stagger` | 0.45 | оглушение после отрубленной руки, с |
| `limb_arm_recover` | 0.8 | следующая атака не раньше, с |
| `limb_arm_speed`, `limb_arm_up` | 260, 420 | вылет руки, px/с |
| `limb_head_speed`, `limb_head_up` | 560, 380 | вылет головы, px/с |
| `limb_head_r` | 14 | радиус головы как снаряда, px |
| `limb_part_kb` | 320 | отброс от головы |
| `limb_part_life` | 2.5 | сколько часть лежит, с |
| `limb_headless_err` | 140 | промах безголового, px |
| `limb_headless_freq` | 0.6 | частота качания промаха, Гц |
| `limb_word_time` | 1.6 | время надписи, с |

В `assets/data/limb_zones.json` для каждого вида: прямоугольники `arm` и `head`,
`attack_states`, однорукие множители `one_arm`, `drops_shield`, цвет и длина руки.

## 8. Критерии приёмки (Acceptance Criteria)

1. Удар сбоку по руке Ауки во время замаха отрубает руку: урон 11 × 1.5 = 16.5, атака
   сорвана, дальность лапы 90 → 54 (`--limb-check`).
2. Второй удар по руке ничего не рубит и наносит обычный урон (юнит-тест и `--limb-check`).
3. Удар по руке вне атаки и удар со спины дают обычный урон (юнит-тест).
4. Удар вниз в прыжке над головой сносит голову: урон 11 × 2 = 22, враг жив (`--limb-check`).
5. Удар вниз с земли, удар сбоку, удар вверх голову не сносят (юнит-тесты).
6. Летящая голова ранит другого врага на 18 и не ранит хозяина (`--limb-check`).
7. Удар по голове, который сам убивает, убивает (юнит-тест).
8. У боссов и у видов без строки в `limb_zones.json` зон нет (юнит-тесты).
9. Без срезов урон прежний: демо печатает `blade dealt [11.0, 11.0, 19.8]`.
10. Скриншоты `production/qa/evidence/limb-arm.png`, `limb-head.png`: видна надпись,
    летящая часть, у врага нет руки или головы.
