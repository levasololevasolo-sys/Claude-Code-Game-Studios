# Благословения (баффы) и дебаффы

> **Статус:** написан по прототипу · **Перенос в Godot:** нет (шаг 9 в `systems-index.md`)
> **Источник:** `prototypes/last-lumen/index.html` — `BUFFS`, `buffN` (~3304–3312), `eliteReward`
> (~3384), места чтения: бег (~688), скорость взмаха `armSpd` (~1314), урон удара (~801),
> урон по герою (~560), убийство (~533), угли (~539), качество оружия (~1244), HUD `drawBuffsHUD` (~3494).
> Описано то, что прототип делает **сейчас**; изменения — в блоках «Предложение».

## 1. Overview (Обзор)

Благословения — шесть простых усилений героя на весь забег: Сила витязя, Быстрые ноги, Дублёная
кожа, Упырья жажда, Железная воля, Удача. Единственный источник в прототипе — побеждённый
**Навий витязь** (элитный враг): в 40% случаев он оставляет три разных благословения-шара, герой
берёт одно. Благословения одного вида **складываются** (два «Силы» = +40%). Они сохраняются до
конца забега и пропадают после него. **Дебаффов на героя в прототипе нет**: все «дебаффы» — это
состояния богов на врагах (горение, заряд, порезы, проклятие), они описаны в `gods-and-runes.md`.

## 2. Player Fantasy (Ощущение игрока)

«Я победил сильного врага — и забрал его силу». Благословение — трофей за риск: витязь опасен,
награда ощутима сразу и навсегда в этом забеге. Выбор из трёх — маленькое решение «под сборку»:
урон для быстрой серии, броня для рискованной игры, удача ради лучшего оружия.

## 3. Detailed Rules (Подробные правила)

### 3.1 Список

| id | Название | Описание в игре | Что делает в коде | Цвет |
|---|---|---|---|---|
| `might` | Сила витязя | +20% урона | урон **ударов оружием** × (1 + 0.2n) | #ff7a5a |
| `haste` | Быстрые ноги | +15% к бегу и скорости ударов | скорость бега × (1 + 0.15n) и скорость взмаха × (1 + 0.15n) | #9ff0d0 |
| `hide` | Дублёная кожа | +25 к здоровью | при взятии: макс. здоровье +25 и здоровье +25 | #e0c080 |
| `vamp` | Упырья жажда | Каждое убийство лечит 2 | каждое убийство лечит 2n | #ff6a7a |
| `iron` | Железная воля | Получаешь на 20% меньше урона | входящий урон × 0.8ⁿ | #b8c4d0 |
| `luck` | Удача | +30% углей, оружие лучше качеством | угли × (1 + 0.3n); бросок редкости оружия сдвигается на 9n (F5) | #ffd36a |

`n` = сколько благословений этого вида у героя (`buffN(id)`).

### 3.2 Получение
- Навий витязь появляется со второй комнаты; при его смерти бросается кубик:
  < 0.4 — три благословения, < 0.7 — три оружия, иначе — богатый сундук.
- Три благословения — **разные** виды, случайные из шести (через `rng()`). Повторы с прошлыми
  благословениями возможны — так и складываются стаки.
- Шары лежат на полу в 140 px друг от друга; «Использовать» (E) у шара — взять. Остальные два
  исчезают.
- Больше нигде благословения не выдаются (ни двери, ни магазин, ни база).

### 3.3 Хранение и сброс
- Благословения хранятся списком `state.buffs`; повторяющийся id = ещё один стак.
- Сохраняются в сохранении забега (сейв-комната) и восстанавливаются при продолжении.
- Новый забег начинается с пустым списком.
- HUD: под полоской здоровья — строки цвета благословения «Название ×n».

### 3.4 Сложение
- `might`, `haste`, `vamp`, `luck`, `hide` — **сложение** (линейно по n).
- `iron` — **умножение** (каждый стак режет оставшийся урон на 20%) — до нуля не доходит.

## 4. Formulas (Формулы)

| Символ | Тип | Диапазон | Описание |
|---|---|---|---|
| n | int | 0 … без ограничения (на практике 0–6 за забег) | число стаков вида |

**F1. Сила витязя:** `k_might = 1 + 0.2 × n`. Диапазон 1 … без потолка. Пример n = 2: 11 × 1.4 = **15.4**.
Действует **только** в `strikeHits` (удары оружием, включая удары вверх/вниз).

**F2. Быстрые ноги:** `k_haste = 1 + 0.15 × n`; бег = `run_speed × k_haste × …`, время взмаха =
`time / swing_speed / (armSpd × k_haste) / …`. Пример n = 2: бег 360 × 1.3 = 468 px/с; взмах меча 0.24 →
0.185 с.

**F3. Упырья жажда:** `heal_on_kill = 2 × n`, ограничено макс. здоровьем. Пример n = 3: +6 за убийство.

**F4. Железная воля:** `k_iron = 0.8ⁿ`. Диапазон (0, 1]. Пример: n = 1 → 0.8; n = 3 → 0.512; n = 5 → 0.328.

**F5. Удача:**
- Угли: `ember_mult ×= 1 + 0.3 × n`. Пример n = 2: ×1.6.
- Оружие: бросок `r = rng()×100 − (tier − 1)×12 − (bonus + 0.5n)×18`; чем меньше `r`, тем выше
  редкость (пороги — в `weapons-and-loot.md`). Один стак = −9 к броску.

**F6. Дублёная кожа:** `max_hp += 25 × (взятия)`, `hp += 25` при каждом взятии.

## 5. Edge Cases (Особые случаи)

- **Благословение, взятое во время боя:** шары доступны в любом режиме комнаты (`anyMode`), их
  можно взять даже пока рядом враги.
- **Убийство при полном здоровье** с Упырьей жаждой: лечение тратится впустую, но число «+2» всё равно всплывает.
- **Сила витязя не усиливает:** доп. оружие (луки, бомбы), рывок с руной, удар о землю, землетрясение
  булавы, Вспышку, статусы. Описание «+20% урона» обещает больше, чем даёт.
- **Быстрые ноги не ускоряют рывок** и его перезарядку.
- **Железная воля** считается **до** щита Живы: щит поглощает уже уменьшенный урон.
- **Дублёная кожа** при выходе из забега: макс. здоровье забега не переносится, сбрасывается.
- **Витязь убит смертью босса** (босс убивает всех врагов комнаты): `eliteReward` не вызывается,
  награды нет.
- **Все 6 одинаковых благословений подряд** возможны — потолка стаков нет.

> **Предложение (дебаффы героя):** разработчик просил «бафы и дебафы». Сейчас дебаффов героя нет.
> Варианты для game-designer: (1) оставить дебаффы только на врагах — проще и честно для новичка;
> (2) добавить проклятые двери «сила с ценой» (например, +40% урона, но −20% здоровья) — даёт
> риск-выбор; (3) статусы от врагов-элит (замедление от Морены, яд Кикиморы). Рекомендую (2): это
> усиливает развилку дверей и путь к «имба-сборке», не требуя новой логики ИИ.

> **Предложение (описание Силы):** либо применить `k_might` ко всему урону героя в `hurtEnemy`,
> либо переписать описание: «+20% урона ударов оружием».

> **Предложение (источники):** бриф обещает баффы за дверью развилки — в коде такой двери нет.
> Добавить тип двери «Благословение» (решает дизайнер дверей).

## 7. Tuning Knobs (Ручки настройки)

**В `config.js` ключей для благословений нет** — все числа зашиты в код. При переносе вынести
в ресурс данных (`BuffDef`) с такими полями и безопасными диапазонами:

| Поле (предлагаемое) | Сейчас | Безопасно | Что меняет |
|---|---|---|---|
| `might_per_stack` | 0.20 | 0.10–0.30 | урон ударов |
| `haste_per_stack` | 0.15 | 0.08–0.20 | бег и взмах; >0.2 за стак ломает ритм комбо |
| `hide_hp` | 25 | 15–40 | макс. здоровье |
| `vamp_heal` | 2 | 1–4 | лечение за убийство |
| `iron_factor` | 0.8 | 0.7–0.9 | входящий урон за стак |
| `luck_embers` | 0.30 | 0.15–0.5 | угли |
| `luck_roll` | 0.5 (×18 = 9) | 0.25–1 | качество оружия |
| `elite_buff_share` | 0.4 | 0.25–0.6 | доля наград витязя «благословения» |
| `buff_offer_count` | 3 | 2–3 | сколько шаров на выбор |

## 8. Acceptance Criteria (Критерии приёмки)

1. При n(`might`) = 2 боковой удар меча №1 по чучелу наносит 15.4.
2. При n(`haste`) = 1 установившийся бег = 414 px/с; время 1-го взмаха меча = 0.2087 ± 0.001 с.
3. Взятие `hide` дважды: макс. здоровье 150, здоровье +50.
4. При n(`vamp`) = 3 убийство врага при 50/100 даёт 56.
5. При n(`iron`) = 2 удар на 20 отнимает 12.8.
6. При n(`luck`) = 1 и одном сиде врагов угли ×1.3 (округление по `dropLoot`).
7. Награда витязя «благословения» всегда показывает 3 **разных** вида; после взятия одного остальные исчезают.
8. Новый забег начинается с `buffs = []`; продолжение из сейв-комнаты восстанавливает тот же список.
9. HUD показывает каждый вид отдельной строкой с числом стаков (скриншот в `production/qa/evidence/`).
10. Все числа таблицы раздела 7 читаются из данных, а не из кода.
