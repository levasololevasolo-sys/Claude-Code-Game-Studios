# Требования доступности «Навь»

Статус: черновик ux-designer, на проверку accessibility-specialist.
Уровень: **Стандартный** (близко к Game Accessibility Guidelines, уровни Basic + часть Intermediate). Платформа PC/Steam, клавиатура и мышь, геймпад.
Связано: art bible §4.5, §4.7; `design/ux/ui-style-guide.md`; `design/ux/settings.md`.

Каждый экран в `design/ux/` проверяется по этому списку перед `/ux-review`.

## 1. Текст и читаемость

| ID | Требование | Как проверить |
|---|---|---|
| A-T1 | Минимум 18 px при 1080p, основной текст 22 px | скриншот всех экранов, замер |
| A-T2 | Масштаб текста 100 / 125 / 150% в настройках; раскладка не обрезает и не перекрывает текст при 150% | скриншот каждого экрана при 150% |
| A-T3 | Контраст текста к подложке не ниже 4.5:1, крупного (от 28 px) не ниже 3:1 | проверка токенов `ui-style-guide` §6 |
| A-T4 | Любой текст поверх игрового мира стоит на подложке `#120D12` 70% | скриншот на снегу Морены и в Топи |
| A-T5 | Подписи в мире не перекрываются: при наложении раздвигаются по вертикали | сцена с 3 подписями рядом |
| A-T6 | Описание руны и оружия: не больше 2 строк, числа выделены жирным и цветом | ревью текстов |

## 2. Цвет и дальтонизм

| ID | Требование |
|---|---|
| A-C1 | Ни одно состояние не передаётся только цветом. У статусов форма (art bible §4.5): горение язычки, мороз корка, кровь капли, проклятие глаз, шок зигзаги, ускорение полосы, щит шестиугольник |
| A-C2 | У богов цвет + знак-форма (§4.3), у редкости цвет + звёзды + форма рамки (§4.6) |
| A-C3 | Стрелки лучше/хуже: форма ▲▼ + цвет + знак числа (+/-) |
| A-C4 | Фокус в меню виден без цвета: толщина рамки, подъём, маркер-ромб |
| A-C5 | Фильтры дальтонизма не обязательны; вместо них проверка всех экранов в симуляции протанопии, дейтеранопии и тританопии (скриншоты в `production/qa/evidence/`) |
| A-C6 | Режим «повышенный контраст»: контур героя и врагов +1 px, подложки 90%, фон приглушён на 20% |

## 3. Звук и субтитры

| ID | Требование |
|---|---|
| A-S1 | Субтитры для всех реплик диалогов, по умолчанию включены |
| A-S2 | Барки (короткие реплики NPC и врагов в мире) тоже как субтитры: плашка над говорящим с именем; если говорящий за кадром, плашка у края экрана со стрелкой в его сторону |
| A-S3 | Размер субтитров 100 / 125 / 150%, фон субтитров 0-100% |
| A-S4 | Важные звуки боя имеют визуальную пару: телеграф удара = свечение + звук + поза (§4.7); атака из-за кадра = стрелка-индикатор у края |
| A-S5 | Раздельные ползунки: общая, музыка, эффекты, голоса, интерфейс |

## 4. Ввод

| ID | Требование |
|---|---|
| A-I1 | Все действия переназначаются на клавиатуре, мыши и геймпаде. Подсказки показывают новые клавиши |
| A-I2 | Вся игра и все меню проходятся только клавиатурой и только геймпадом. Мышь не обязательна |
| A-I3 | Удержание (hold) везде имеет замену: настройка «удержание → нажатие» (тогда второе нажатие подтверждает) |
| A-I4 | Быстрые повторные нажатия (если будут) имеют замену удержанием |
| A-I5 | Защита от случайного выбора: 0.35 с после открытия экрана выбора подтверждение не принимается |
| A-I6 | Мёртвая зона стиков 0.05-0.40 в настройках, по умолчанию 0.20 |
| A-I7 | Опция «рывок в сторону стика / в сторону взгляда» |
| A-I8 | Пауза доступна в любой момент боя, кроме кат-сцены (там: пропуск или пауза) |

## 5. Движение, тряска, вспышки

| ID | Требование |
|---|---|
| A-M1 | Тряска экрана 0-100% (по умолчанию 100) |
| A-M2 | Вспышки экрана (белые кадры при крите, Вспышке, молнии) 0-100%; при 0 заменяются затемнением краёв |
| A-M3 | Нет мигания чаще 3 раз в секунду на большой площади экрана ни при каких настройках |
| A-M4 | Предупреждение о вспышках на первом запуске до главного меню |
| A-M5 | «Меньше движения» в UI: анимации заменяются растворением 0.1 с |
| A-M6 | Замедление времени (хитстоп) нельзя отключить полностью, но можно уменьшить до 50% |
| A-M7 | Виньетка низкого здоровья и стук сердца отключаются отдельно |

## 6. Сложность и время

| ID | Требование |
|---|---|
| A-D1 | Экраны выбора (руна, бог, оружие) ставят игру на паузу; времени на чтение нет ограничения |
| A-D2 | Диалоги идут только по нажатию; авто-режим с выбором скорости |
| A-D3 | Три уровня сложности «Сказка» / «Былина» / «Навь» (данные в `assets/data/difficulty.json`): выбор при новом сохранении, смена в настройках в любой момент. На экране всегда список того, что меняет уровень. Без наказания и насмешки за лёгкий уровень. Отдельно от уровней Пепла после победы (см. `design/ux/main-menu.md`, `design/ux/settings.md`) |

## 7. Чек-лист на каждый экран

- [ ] Проходится только клавиатурой
- [ ] Проходится только геймпадом
- [ ] Текст не меньше 18 px при 1080p и читается при 150%
- [ ] Ничего не передаётся только цветом
- [ ] Нет вспышек без отключения
- [ ] Реплики имеют субтитры
- [ ] Раскладка верна при 1920x1080 и 2560x1440
- [ ] Подсказки ввода показывают глифы текущего устройства
