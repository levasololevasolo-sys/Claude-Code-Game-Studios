# Экран: лавка на заставе (Кузнец Потап и другие станции)

Код: `src/base/shop_screen.gd`, правила `src/base/shop_rules.gd`, станции `src/base/station.gd`. Стиль: «покой», полное дерево и орнамент. Один шаблон для всех станций (Потап, Ведунья Сова, Пряха Доля и т.д.).

## 1. Цель

Игрок видит, что купить, сколько это даст в числах, хватает ли ресурсов и как изменится облик героя.

## 3. Содержание

- **Число эффекта** всегда: «+20 здоровья», «-8% урона по тебе», «перезарядка рывка -0.3 с».
- **Цена:** иконка + число; хватает: `ui.text` и ✓; не хватает: `ui.danger`, ✕ и «нужно ещё 4».
- **Закрыто:** значок замка в строке, причина в правой панели одной строкой («Сначала очелье, ярус 1»). Внизу экрана причина не повторяется.
- **Превью облика:** герой сейчас и после покупки, новая деталь подсвечена нитью.
- «Уйти» не пункт списка: только кнопка-подсказка.

## 4. Состояния

| Состояние | Вид |
|---|---|
| Открытие | окно выезжает снизу 0.15 с, Потап говорит одну реплику (субтитр в шапке) |
| Фокус строки | рамка `ui.select`, маркер-ромб, правая панель меняется за 0.1 с |
| Покупка | молот бьёт по ячейке, искры, ресурсы в шапке убывают счётом 0.4 с, ярус заполняется, на превью деталь вспыхивает |
| Не хватает / закрыто | кнопка «Сковать» серая с замком, при нажатии лязг и дрожь 4 px, ресурс, которого нет, мигает рамкой один раз |
| Новое в лавке | ромбик у строки и у имени станции в мире |

## 4.1 Звук и анимация

| Фаза | Анимация | Звук |
|---|---|---|
| Открытие | окно выезжает снизу на 80 px за 250 мс (`TRANS_CUBIC EASE_OUT`), с лёгким «ударом» в конце (сдвиг 3 px вниз и назад за 60 мс, без пружины); строки списка проявляются шагом 30 мс, превью героя проявляется 200 мс | `ui_shop_knock` |
| Фокус строки | правая панель меняется растворением 100 мс | `ui_hover_wood` |
| Покупка | молот бьёт по ячейке (иконка 80 мс вниз), искры 300 мс, счёт ресурсов 300 мс | `ui_forge_buy`, `ui_count_tick` |
| Нельзя | дрожь 4 px 150 мс | `ui_error_clank` |
| Смена станции | `ui_page_turn`, содержимое сдвиг 24 px 150 мс | `ui_page_turn` |
| Закрытие | окно уходит вниз 150 мс (`TRANS_QUAD EASE_IN`) | `ui_close` |

Любое нажатие в первые 300 мс доводит открытие до конца без покупки.

## 5. Ввод

| Действие | Клавиатура / мышь | Геймпад |
|---|---|---|
| Выбор | ↑ ↓ / W S, мышь | крестовина, стик |
| Купить | Enter / E / ЛКМ по кнопке | A |
| Уйти | Esc / ПКМ | B |
| Другая станция (если их несколько у NPC) | Q / R (переназначаемо) | LB / RB |

Покупка нажатием, без удержания. Дорогие покупки (дороже 25% запаса углей): второе нажатие в течение 2 с («Нажми ещё раз, чтобы сковать»). Удержание не используется (см. A-I3).

## 6. Критерии приёмки

1. У каждого товара число эффекта.
2. Видно по каждому ресурсу, хватает ли его, без опоры на цвет (✓ / ✕).
3. Закрытый товар с замком и одной причиной, без дубля.
4. Превью облика меняется при смене строки.
5. Один шаблон работает для всех станций (скриншоты двух станций).
