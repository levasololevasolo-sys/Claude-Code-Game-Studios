# Экран: пауза, сборка, кодекс (новый)

Код: нет (новый экран). Стиль: «покой». Игровое время на паузе.

## 1. Цель

В любой момент забега игрок может остановиться, посмотреть свою сборку (руны, оружие, оберег, союзы) с точными числами, почитать кодекс и выйти в настройки или меню.

## 2. Структура (вкладки)

`СБОРКА · ОРУЖИЕ · КОДЕКС · НАСТРОЙКИ · ВЫХОД`

Открытие: Esc / Start открывает на «Сборке». Tab / View открывает сразу «Сборку» (быстрый взгляд) и закрывается той же кнопкой.

## 4. Другие вкладки

- **Оружие:** две ячейки с полной карточкой (числа в настоящих единицах: урон, удары в секунду, дальность в шагах героя), свойство, редкость.
- **Кодекс:** береста. Разделы: Боги, Нечисть, Люди заставы, Руны, Места, Записки. Слева список (новое с ромбиком), справа страница: рисунок, текст лора, для нечисти слабости и статусы. Не встреченное: силуэт и «???». Открывается и с заставы.
- **Настройки:** тот же экран, что `settings.md`, внутри вкладки.
- **Выход:** «Продолжить», «На заставу (забег потерян)», «В главное меню», «Выйти из игры». Два последних и «На заставу» с подтверждением: окно «Забег будет потерян. Угли сохранятся.» (решение разработчика 27.11: угли забега при выходе через паузу сохраняются, как при смерти).

## 5. Звук и анимация

| Фаза | Анимация | Звук |
|---|---|---|
| Открытие | игра замирает в первый кадр; затемнение `#0B0709` 0.80 за 150 мс; ряд вкладок опускается сверху на 16 px, панели выезжают на 12 px, шаг 40 мс, всё до 300 мс (`TRANS_CUBIC EASE_OUT`) | `ui_open_wood` |
| Быстрая сборка (Tab) | то же, но 200 мс | `ui_open_wood` (тише на 3 dB) |
| Фокус иконки | рамка, правая панель растворением 100 мс | `ui_hover_wood` |
| Смена вкладки | содержимое сдвигается на 24 px в сторону перехода, 150 мс | `ui_page_turn` |
| Страница кодекса | перелист: старая уходит влево с поворотом 8°, 200 мс | `ui_page_turn`; новая запись `ui_codex_new` |
| Подтверждение выхода | окно появляется 150 мс | `ui_open_wood`; «да» `ui_confirm_gold` |
| Закрытие | 150 мс (`TRANS_QUAD EASE_IN`), затем разморозка времени 200 мс | `ui_close` |

Нажатие во время открытия доводит его до конца.

## 6. Ввод

| Действие | Клавиатура / мышь | Геймпад |
|---|---|---|
| Открыть / закрыть паузу | Esc | Start |
| Сборка (быстро) | Tab | View |
| Вкладки | Q / E, клик | LB / RB |
| Навигация | стрелки / WASD, мышь | крестовина, стик |
| Подробнее / выбрать | Enter / ЛКМ | A |
| Назад | Esc / ПКМ | B |

## 7. Критерии приёмки

1. Пауза открывается из любого места боя за 1 нажатие, время стоит (тест).
2. На «Сборке» видны все руны, слоты, союзы, оберег, покровители; у каждой руны описание с числами.
3. Пустые слоты обозначены.
4. Кодекс показывает новые записи ромбиком.
5. Выход из забега всегда с подтверждением и понятным последствием.
6. Проходится только геймпадом и только клавиатурой. Скриншоты каждой вкладки 1080p.
