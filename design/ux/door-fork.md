# Экран в мире: развилка дверей

Код: двери в `src/world/` (подписи рисуются в мире). Это не меню, игрок ходит. Стиль: подписи в мире (`ui-style-guide` §3, плашка).

## 1. Цель

Издалека видно, что за каждой дверью (награда) и какая дверь выбрана. Подпись не налезает на соседние и не теряется на фоне.

## 2. Раскладка (мир, при 1080p, двери шириной 140 px)

```
          +-------------+        +-------------+        +-------------+
          | (медальон 72)|       | (медальон 72)|       | (медальон 72)|     плашка 220x120
          | Руна Сварога |       | Руна Велеса  |       | Угли x 60    |     PT Sans Bold 22
          |  [E] Войти   |       |              |       |              |     только у ближней
          +-------------+        +-------------+        +-------------+
             /арка\                 /арка\                 /арка\
            | дверь|               | дверь|               | дверь|           наличник с резьбой,
            | свет |               |      |               |      |           свет цвета награды
```

- Над каждой дверью: медальон награды 72 px и плашка с одной строкой «Руна Сварога» (без «за следующей комнатой:»; это поясняется один раз в первой развилке подсказкой).
- Плашки не ближе 24 px друг к другу; при наложении уменьшаются до медальона + 18 px текста.
- Дверь: рисованная арка с наличником (задача art-director), щель света цветом бога награды.

## 3. Состояния

| Состояние | Вид |
|---|---|
| Далеко | медальон и строка, 80% яркости |
| Рядом (ближайшая) | плашка 100%, рамка `ui.select`, глиф «[E] Войти», дверь светится ярче, тихий звон |
| Вход | дверь открывается 0.3 с, свет заливает экран, переход |
| Хозяин побеждён ещё не всеми (если двери закрыты) | замок на плашке + строка причины |

## 3.1 Звук и анимация

- Подход к двери: плашка растёт с 80% до 100% за 150 мс (`TRANS_CUBIC EASE_OUT`), `ui_door_near` с высотой цвета награды.
- Отход: обратно за 120 мс, без звука.
- Вход: дверь открывается 300 мс, затем переход в комнату (затемнение 200 мс). Звук двери от sound-designer (не UI).

## 4. Ввод

Войти: E / A (Cross). Без меню, без подтверждения.

## 5. Критерии приёмки

1. Скриншот 1080p в Топи и в Морене: все три подписи читаются, не перекрываются, не уходят за край.
2. Глиф показан только у ближайшей двери и только текущего устройства.
3. Награду различает игрок без цвета (знак бога, иконка углей).
