# Экран: настройки (новый)

Код: нет (новый экран). Открывается из главного меню и из паузы (вкладка). Стиль: «покой». Требования: `design/accessibility-requirements.md`.

## 1. Цель

Всё, что нужно для комфорта, в 5 разделах; изменения видно сразу; ничего не теряется без спроса.

## 2. Раскладка 1920x1080

```
 y=48    [LB]  ИГРА   ЗВУК   ИЗОБРАЖЕНИЕ   УПРАВЛЕНИЕ   ДОСТУПНОСТЬ  [RB]
 y=140
 +------------------- 1100 --------------------+ +------------ 656 ------------+
 | Громкость общая      [========--]  80       | | (описание пункта в фокусе)   |
 | Музыка               [======----]  60       | | Меняет громкость музыки.     |
 | ...                                         | | Сейчас играет пример звука.  |
 | строка 72 px, название PT Sans 24,          | |                              |
 | значение справа, ◀ ▶ у переключателей       | |                              |
 +---------------------------------------------+ +------------------------------+
 y=1000   [X] По умолчанию        [A] Изменить  [B] Назад
```

## 3. Разделы

### Игра
- **Сложность:** ◀ Сказка / Былина / Навь ▶. Правая панель показывает список изменений из `assets/data/difficulty.json` в сравнении с текущей (стрелки ▲▼ и числа). Смена в любой момент; в забеге действует с следующей комнаты (или сразу: решает game-designer), подтверждение «Сменить на Сказку?» с тем же списком. Строка: «Сюжет и награды не меняются». Пепел здесь не настраивается.
- Числа урона: вкл / выкл. Подсказки обучения: вкл / выкл. Скорость текста: 30 / 60 / сразу. Язык.

### Звук
Общая, музыка, эффекты, голоса, интерфейс (0-100, шаг 5). При смене ползунка звучит пример этого канала. Звук в фоне: вкл / выкл.

### Изображение
Режим окна (оконный / без рамки / полный экран), разрешение, VSync, предел кадров (30 / 60 / 120 / 144 / нет), яркость (с образцом: «знак должен быть едва виден»), масштаб HUD 80-120%, HUD по центру на широких экранах, пост-обработка (зерно, виньетка) вкл / выкл.
Смена разрешения или режима: окно «Оставить? Возврат через 10 с».

### Управление
- Две вкладки: Клавиатура и мышь / Геймпад.
- Таблица: действие | основная | дополнительная. Выбор ячейки, затем «Нажми клавишу...» (Esc отменяет, 5 с таймаут).
- Конфликт: обе строки подсвечиваются `ui.danger` со значком ⚠ и текстом «Уже на "Рывок". Поменять местами?» [Да] [Нет].
- Нельзя оставить без клавиши: подтверждение, пауза, меню. Esc и Start в меню не переназначаются.
- Мёртвая зона стиков, вибрация 0-100%, рывок по стику / по взгляду, удержание → нажатие.
- Сброс раздела к умолчанию с подтверждением.

### Доступность
Масштаб текста 100 / 125 / 150% (с примером). Размер и фон субтитров. Тряска экрана 0-100%. Вспышки 0-100%. Меньше движения в UI. Повышенный контраст. Виньетка низкого здоровья, стук сердца. Хитстоп 50-100%. Удержание → нажатие. Индикатор атак из-за кадра. Курсор мыши крупнее.

## 4. Состояния

| Состояние | Вид |
|---|---|
| Фокус строки | рамка `ui.select`, ромб-маркер, справа описание |
| Изменено, не по умолчанию | маленький ромб слева от названия |

| Сохранение | автоматически при выходе из раздела; значок веретена в углу 1 с |

## 5. Ввод

| Действие | Клавиатура / мышь | Геймпад |
|---|---|---|
| Разделы | Q / E, клик | LB / RB |
| Строки | ↑ ↓ | крестовина |
| Значение | ← → , колесо, перетаскивание | ← → |
| Изменить / переназначить | Enter / ЛКМ | A |
| По умолчанию | Delete / R | X |
| Назад | Esc / ПКМ | B |

## 6. Критерии приёмки

1. Все пункты из `accessibility-requirements.md` §1-§5 есть на экране.
2. Сложность меняется здесь, справа виден список изменений из `difficulty.json`, есть подтверждение.
3. Переназначение показывает конфликт и предлагает обмен; подсказки в игре сразу показывают новые клавиши.
4. Масштаб текста 150% не ломает ни один раздел (скриншоты).
5. Смена разрешения с откатом через 10 с.
6. Проходится только геймпадом и только клавиатурой.
