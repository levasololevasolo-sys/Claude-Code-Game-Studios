# Окно диалога и барки

Код: `src/base/dialogue_box.gd`, правила `src/base/dialogue_rules.gd`; пролог `src/story/`. Стиль: «покой».

## 1. Цель

Игрок всегда видит, кто говорит, читает в своём темпе, не теряет реплики и видит говорящих в мире (окно их не закрывает).

## 2. Раскладка 1920x1080

```
 камера при диалоге поднимается на 120 px, герой и собеседник в верхних 2/3 экрана
 y=780
      +--------------------------------------------------------------------+
  (портрет 240x280,   ПРЯХА ДОЛЯ                                          |  Philosopher Bold 30, цвет NPC
   выходит за рамку   Встал. Голый, как из бани, зато живой.               |  PT Sans 26, до 3 строк
   вверх на 80 px)    Это нить тебя дёрнула назад.                         |
      |                                                         (узелок ▼) |  индикатор «дальше»
      +--------------------------------------------------------------------+
 y=1032          x 280..1640 (окно 1360x252)          [A] Дальше  [Y] Журнал  [B] Пропуск
```

- Портрет: рисованный бюст в стиле героя, слева; у героя (если говорит) портрет справа. Эмоции: 3 варианта (спокойно, сердито, смешно) на NPC.
- Говорящий за кадром («Потап, с башни»): портрет с тонированной рамкой и строка-место.

## 3. Текст и выбор

- Печать текста 60 знаков в секунду (настройка: 30 / 60 / мгновенно).
- Первое нажатие дописывает реплику, второе переходит к следующей.
- Варианты ответа: список над окном справа, до 4 пунктов, PT Sans 24, фокус как у кнопок.
- Журнал (Y / Tab): последние 50 реплик, береста, прокрутка.
- Пропуск (B / Esc удержание 0.6 с или двойное нажатие при настройке A-I3): только для уже прочитанных реплик или всей сцены с подтверждением.

## 4. Барки (субтитры в мире)

- Плашка над головой говорящего: имя 18 + текст PT Sans 22, ширина до 520 px, 3 с + 0.05 с на знак.
- Если говорящий за кадром: плашка у края экрана со стрелкой.
- Не больше 2 барков одновременно; при наложении сдвигаются.
- Во время экранов выбора барки ставятся в очередь, не просвечивают.

## 5. Состояния

| Состояние | Вид |
|---|---|
| Открытие | окно выезжает снизу 0.15 с, портрет проявляется 0.2 с, HUD уходит |
| Печать | узелок скрыт |
| Дописано | узелок ▼ покачивается (выключается с «меньше движения») |
| Смена говорящего | портреты меняются растворением 0.1 с, имя меняет цвет |
| Закрытие | окно уходит вниз 0.10 с, камера возвращается 0.3 с |

## 5.1 Звук и анимация

| Фаза | Анимация | Звук |
|---|---|---|
| Открытие | окно «разворачивается как береста»: сначала полоса 1360x8 по центру, затем раскрывается по высоте до 252 за 250 мс (`TRANS_SINE EASE_IN_OUT`); края свитка (валики 16 px) уходят вверх и вниз; портрет проявляется и поднимается на 16 px 200 мс, начиная со 150 мс | `ui_bark_unroll` |
| Печать | знаки появляются по скорости из настроек | `ui_text_tick` (выключается в настройках) |
| Смена говорящего | растворение портрета 100 мс | нет |
| Варианты ответа | выезжают справа шагом 40 мс, 150 мс | `ui_card_deal` |
| Журнал | береста выезжает справа 200 мс | `ui_page_turn` |
| Закрытие | свиток сворачивается по высоте 150 мс (`TRANS_QUAD EASE_IN`) | `ui_close` |

Барки: плашка проявляется 120 мс, уходит 200 мс, без звука (голос NPC, если будет, ведёт sound-designer). Нажатие во время разворота доводит его до конца и не листает реплику.

## 6. Ввод

| Действие | Клавиатура / мышь | Геймпад |
|---|---|---|
| Дальше / дописать | Enter / E / Пробел / ЛКМ | A |
| Выбор ответа | ↑ ↓, 1-4, мышь | крестовина |
| Журнал | Tab | Y |
| Пропуск | Esc (удержание) | B (удержание) |

## 7. Критерии приёмки

1. Окно не перекрывает ни героя, ни собеседника (скриншот на заставе).
2. Есть портрет и имя у каждой реплики.
3. Первое нажатие дописывает, второе листает (тест).
4. Журнал показывает прошлые реплики.
5. Барки читаются на снегу Морены и не просвечивают сквозь меню.
