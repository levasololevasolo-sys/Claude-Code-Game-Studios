# Экран: главное меню (новый)

Код: нет (новый экран). Стиль: «покой», самый нарядный экран игры.

## 1. Цель

Первый взгляд на игру. Красиво и тихо; за 1 нажатие продолжить игру.

## 2. Поток

```
запуск -> предупреждение о вспышках (только первый раз, A-M4) -> логотип студии (пропуск) -> главное меню
главное меню:
  Продолжить      (если есть сохранение; в фокусе по умолчанию)
  Новая игра  -> [есть сохранение? -> подтверждение перезаписи] -> выбор сложности -> пролог
  Настройки   -> settings.md
  Кодекс      (если открыта хоть одна запись)
  Титры
  Выйти       -> подтверждение
```

Слоты сохранений: 5 (решение разработчика 27.11). «Новая игра» и «Продолжить» сначала показывают список из 5 слотов: имя героя или «Пусто», локация, число забегов, время игры; удаление слота с подтверждением.

## 3. Раскладка 1920x1080

```
 фон: живая сцена (застава ночью или Топь, параллакс, огонь, частицы), герой сидит у костра
 x=160, y=200   Н А В Ь                         (логотип Ruslan 140, золото с нитью)
                сказ о павшем богатыре          (Philosopher 28, ui.text_dim)
 x=160, y=520   ◆ Продолжить                    (PT Sans Bold 32, фокус: ромб + ui.select + нить под словом)
                  Топь Кикиморы · 12 забегов · Былина   (PT Sans 18 ui.text_dim, только у «Продолжить»)
                  Новая игра
                  Настройки
                  Кодекс
                  Титры
                  Выйти
 y=1000  v0.3.1                                              [A] Выбрать   [B] Назад
```

Пункты: шаг 64 px, зона клика 480x56. Меню слева, сцена справа видна.

## 4. Выбор сложности (после «Новая игра»)

Три карточки как в `rune-offer.md` (420x560), по центру. Значения берутся из `assets/data/difficulty.json`; текст строк собирается из данных, не пишется руками. Числа ниже только пример раскладки, их задаёт game-designer.

```
 +------ СКАЗКА ------+   +------ БЫЛИНА ------+   +------- НАВЬ -------+
 | (знак: прялка)     |   | (знак: меч)        |   | (знак: череп-оберег)|
 | Для истории        |   | Как задумано       |   | Для тех, кто       |
 |                    |   | (Рекомендуем)      |   | прошёл Былину      |
 | Урон по тебе  -40% |   | Урон по тебе 100%  |   | Урон по тебе +25%  |
 | Здоровье      +30% |   | ...                |   | Враги быстрее +10% |
 | Окно рывка  дольше |   |                    |   | Меньше лечения     |
 | Угли         те же |   |                    |   | Угли          +15% |
 +--------------------+   +--------------------+   +--------------------+
   «Сложность можно сменить в любой момент в Настройках. Награды и сюжет те же.»
```

- По умолчанию фокус на «Былине».
- Каждая строка: что меняется + значение + стрелка ▲▼ против Былины.
- Текст без насмешки: «Для истории», не «Для слабаков».
- **Пепел** (уровни сложности после победы) здесь не показывается: он открывается в мире после первой победы и живёт на своём экране. Подпись в карточке «Навь» не должна путать с Пеплом.
- Если «Навь» закрыта до прохождения Былины (решение game-designer): замок и причина.

## 5. Звук и анимация

| Фаза | Анимация | Звук |
|---|---|---|
| Первый вход после запуска | фон из чёрного 400 мс; логотип: нить «вышивает» буквы слева направо 400 мс (`TRANS_SINE EASE_IN_OUT`), параллельно; пункты меню выезжают слева на 24 px шагом 40 мс | `ui_menu_start`, музыка меню входит за 1 с (не блокирует) |
| Возврат из настроек / паузы | без логотипа, пункты 200 мс | `ui_close` |
| Фокус | ромб-маркер, текст `ui.select`, нить подчёркивает слово 150 мс | `ui_hover_wood` |
| Подтверждение | нить вспыхивает 120 мс, экран в чёрное 300 мс | `ui_confirm_gold` |
| Карточки сложности | раздаются как руны (`rune-offer.md` §4.1), без переворота, шаг 60 мс | `ui_open_wood`, `ui_card_deal` x3; выбор `ui_rune_select` |
| Окно подтверждения | 150 мс | `ui_open_wood`; «нет» `ui_cancel_wood` |

Любое нажатие во время входа показывает меню сразу. Нет сохранения: «Продолжить» не показывается (не серым), фокус на «Новая игра».

## 6. Ввод

↑ ↓ / W S / мышь / крестовина; Enter, E, ЛКМ, A; Esc, ПКМ, B: назад. Курсор мыши скрыт, пока игрок пользуется клавиатурой или геймпадом.

## 7. Критерии приёмки

1. С сохранением фокус на «Продолжить», одно нажатие загружает игру.
2. «Новая игра» при наличии сохранения требует подтверждения перезаписи.
3. Выбор сложности показывает для каждого уровня список изменений из `difficulty.json`.
4. Надпись о смене сложности в настройках есть на экране выбора.
5. Пепел на экране выбора сложности не упоминается как уровень.
6. Скриншоты меню и выбора сложности 1080p и 1440p.
