# HUD в бою

Статус: черновик ux-designer. Код: `src/ui/amulet_hud.gd`, `src/ui/weapon_hud.gd` (будет общий `hud.gd`). Стиль: `ui-style-guide.md`, режим «бой» (тонкая рамка, без орнамента). Доступность: `design/accessibility-requirements.md`.

## 1. Цель

Игрок за полсекунды взгляда в угол знает: сколько здоровья, готов ли оберег, что в руках, что готово к удару. Всё остальное приходит на секунду и уходит.

## 3. Что значит «Коло 0%»

Подпись убрать. Имя оберега игрок видит в паузе. На HUD только дуга заряда. На 100% медальон загорается светом бога, вокруг бежит нить, звучит тихий звон, глиф Вспышки появляется рядом с медальоном. Значения выше 100% (на скриншоте «150%») показываются второй, внешней дугой, если механика это сохраняет (вопрос к game-designer).

## 4. Состояния

| Состояние | Что видно |
|---|---|
| Норма | всё как выше, подложки `ui.bg_soft` 85% |
| Урон | полоса здоровья вздрагивает (2 px, 0.1 с), потерянная часть светлеет и стекает за 0.4 с |
| Мало здоровья (меньше 25%) | число здоровья пульсирует `ui.danger`, мягкая красная виньетка, стук сердца (оба отключаются) |
| Лечение | зелёные искры Живы + число «+N» над полосой |
| Оберег готов | см. §3 |
| Перезарядка оружия / руны | затемнение ячейки снизу вверх, в конце вспышка рамки |
| Подбор руны | медальон летит из экрана выбора в свой слот за 0.4 с |
| Диалог, выбор, пауза | HUD уходит прозрачностью до 0 за 0.15 с (сейчас просвечивает) |
| Застава | скрыты оружие, руны, оберег; справа все ресурсы заставы постоянно |
| Без боя 5 с | руны и ресурсы гаснут до 50% |

## 5. Подсказки ввода

- Глифы только текущего устройства (`ui-style-guide` §12).
- Подсказки действий с предметами в мире: над предметом, плашка, «[E] Взять», PT Sans 22. Не больше одной подсказки сразу (у ближайшего).

## 6. Числа урона и барки

- Числа урона PT Sans Bold 28, контур 3 px, крит +30% и золото, разлетаются вверх-вбок 0.6 с, раздвигаются при наложении. Отключаются в настройках.
- Барки: плашка над говорящим, имя Philosopher 18 `ui.text_dim` + текст PT Sans 22, 3 с. Говорящий за кадром: у края экрана со стрелкой.
- Отладочный оверлей только по F3, в релизной сборке отсутствует.

## 7. Ввод

HUD не принимает ввод. Пауза: Esc / Start. Сборка сразу: Tab / View.

## 7.1 Звук и анимация

- HUD не «открывается» в бою. При входе в забег: блоки выезжают из-за края 300 мс, `TRANS_CUBIC EASE_OUT`, со сдвигом 40 мс между блоками, без звука.
- Уход при открытии меню: прозрачность до 0 за 150 мс; возврат 200 мс.
- Оберег готов: свечение 300 мс, звук `ui_thread_run` (тихо). Подбор угля: `ui_count_tick` раз на подбор.
- Пропуск не нужен: HUD не блокирует ввод.

## 8. Критерии приёмки

1. На скриншотах 1920x1080 и 2560x1440 видны здоровье с числом, щит, оберег со знаком бога, два оружия, три руны, угли.
2. Нет текста меньше 18 px. Нет надписей «Коло», «состояние: ...».
3. При геймпаде глифы в ячейках оружия Xbox/PS, при клавиатуре колпачки клавиш; смена без перезапуска.
4. При открытии выбора руны HUD не виден под затемнением.
5. Мало здоровья различимо в ч/б (пульс числа и виньетка, не только цвет).
6. В Морене (светлый фон) все элементы HUD читаются (скриншот).
7. Масштаб HUD 80% и 120% не выводит элементы за поля.
