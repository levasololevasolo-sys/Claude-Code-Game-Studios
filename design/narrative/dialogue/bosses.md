# Реплики хозяев: Навь

> **Статус:** черновик 1, writer, 2026-11-27. Provisional. Канон: `characters.md` 4, `story-beats-by-run.md` 5.
> **Данные:** `assets/data/dialogue.json`, массив `boss_lines`. Код его пока не читает.

## 0. Как читать

- `moment`: `intro` (строка над хозяином при входе, 2 с, бой не ждёт), `hero_death` (во время
  рывка нити), `defeat` (поражение хозяина), `choice` (перед кнопками выбора).
- Условия `when`: `kills_min/max` по `save.bosses`, `deaths_min/max` по `deaths_by`, `ash_min`,
  `needle`, `flags_all`, `flags_none`. `once` значит строка звучит один раз за игру.
- **Выбор строки (предложение):** из подходящих брать самую точную (больше условий), при
  равенстве `once` раньше повторной, потом порядок в файле. **[нужно решение: lead-programmer]**
- `kills_min 1, kills_max 1, once` на `intro` это «почему я снова жив»: первая встреча после
  первой победы над этим хозяином. Ответ всегда один: смерть не может забрать, Навь подымает.
- Горыныч: головы **Л** (злая, усталая), **С** (гордая, сторожевая), **П** (молодая, голодная).
  Спор голов только в одной строке на бой (`gor_intro_2b`). Без шуток про еду героя.
- Кощей до первой победы не говорит о мосте и о деде. После неё может.
