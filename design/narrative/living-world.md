## 1. Система триггеров реплик

### 1.1 Как это выглядит для игрока

Герой вернулся на заставу. Над теми, кому есть что сказать нового, горит искра (библия 3.1).
Каждый NPC говорит **одну реплику за заход**. Он помнит, где ты пал, кто тебя убил, какого
бога ты встретил. Сюжетная реплика звучит один раз. Когда нового нет, звучит бытовая.

### 1.2 Ключи событий

События бывают двух видов. **Свежие**: случились в последнем забеге, живут до конца
следующего захода на заставу. **Постоянные**: состояние сохранения, живут всегда.

| Ключ | Вид | Параметр | Откуда берётся |
|---|---|---|---|
| `first_visit` | свежее | нет | `save.runs == 0` при первом входе |
| `death` | свежее | `location`, `killer`, `room` | итог забега (`economy-and-meta.md` 3.8 «где пал») |
| `first_death` | свежее | нет | `death` и `save.runs == 1` |
| `death_to_boss` | свежее | `boss`, `n` = `deaths_by[boss]` | `death`, если `killer` это id хозяина |
| `killed_by` | свежее | `enemy`, `n` = `killed_by_count[enemy]` | `death`, если `killer` обычный враг или витязь |
| `return_home` | свежее | `location` | исход «Вернулся с добычей» |
| `rune_first` | свежее | `god` | первая руна бога за всю игру (`gods_seen`) |
| `duo_first` | свежее | `pair` | первый союз за всю игру (`duos_seen`) |
| `weapon_found` | свежее | `weapon`, `total` | первое выпадение вида оружия в забеге (`weapons_found`) |
| `boss_beaten` | свежее | `boss`, `n` = `save.bosses[boss]` | итог забега |
| `needle_found` | свежее | `n` | открыт Тайник с иглой (`needle_count`) |
| `win` | свежее | `ash`, `needle` (да/нет), `n` = `save.wins` | `endRun` с победой |
| `runs` | постоянное | `n` = `save.runs` | счётчик |
| `title` | постоянное | `tier` 0..4 | самый низкий ярус доспеха |
| `ash_unlocked` | постоянное | `n` = `save.maxAsh` | `economy-and-meta.md` 3.9 |
| `ash_win` | постоянное | `n` | `save.ashWins[n]` |
| `flag` | постоянное | `name` | флаг, поставленный другой репликой (цепочки) |
| `ambient` | всегда | нет | бытовая реплика |

`location`: `swamp`, `forest`, `realm`, `bridge`, `kingdom`. `boss`: `clockmaker`, `warden`,
`queen`, `gorynych`, `koschei`. `god`: `svarog`, `perun`, `veles`, `stribog`, `zhiva`, `rod`.
**[нужно решение: lead-programmer, id локаций; здесь условные]** В данных хозяева уже по

Новые ключи writer (2026-11-27, код их ещё не шлёт): `death_streak` (`n` смертей подряд),
`embers_spent` (`n` трат углей у Чура), `win_no_needle` (победа без иглы, `n` = `save.wins`).
Подробно: `dialogue/base-npcs.md` 0.

### 1.3 Приоритеты и правило выбора

| Полоса | Приоритет | Что туда входит |
|---|---|---|
| Главная линия | 100 | звания, первая победа, победы на Пепле, имя героя, признание Потапа |
| Вехи хозяев | 90 | `boss_beaten` n=1 и n=3, `needle_found` n=1 |
| Первые встречи | 80 | `first_visit`, `first_death`, приход Офени |
| Смерть от хозяина | 70 | `death_to_boss` n=1, 3, 5 |
| Смерть от врага | 60 | `killed_by` n=1 |
| Находки | 50 | `rune_first`, `duo_first`, `weapon_found` (первое и каждое 10-е) |
| Место смерти | 45 | `death` по `location`, без `once` |
| Счётчики | 40 | `runs` 5, 10, 25, 50, 100 |
| Бытовые | 10 | `ambient` |

Алгоритм при входе на заставу (для каждого NPC по очереди: Доля, Потап, Сова, Баюн, Чур, Офеня):

1. Собрать **кандидатов**: реплики этого NPC, у которых выполнены все условия `when` и
   которые не сказаны (если `once`).
2. **Правило одного события.** Если свежее событие уже «забрал» NPC раньше по очереди, у
   остальных реплики на то же событие теряют 30 приоритета. Исключение: `chorus: true`
   (первая победа, все говорят). Так шесть NPC не повторяют одно и то же.
3. Взять реплику с наибольшим приоритетом. При равенстве: та, у которой больше условий
   (точнее), потом порядок в файле.
4. Если `once`, записать `id` в `said`. Если есть `sets`, поставить флаги.
5. Если кандидатов нет, взять `ambient`, которая не звучала последние 3 захода.
6. **Искра** над NPC горит, если выбрана реплика с приоритетом 40 и выше.
7. Свежие события сгорают в конце захода. Несказанная реплика на свежее событие теряется,
   и это нормально: в следующий раз будет новое.

**Цепочки.** Реплика может требовать, чтобы другая уже прозвучала (`after`). Пример: Пряха
говорит строку 3 цепочки только после строки 2.

### 1.5 Формат `assets/data/dialogue.json` (предложение)

Текст лежит по ключу перевода (`text`), русский дублируется в `ru` для писателя. Подстановки
только именованные: `{title}`, `{runs}`, `{hero}` (до сцены имени это «Нитка» у Потапа).

```json
{
  "version": 2,
  "lines": [
    {
      "id": "dolya_gorynych_3",
      "npc": "dolya",
      "text": "DLG_DOLYA_GORYNYCH_3",
      "ru": "Ты падаешь там, где пал тогда. Нить помнит. Попробуй помнить меньше.",
      "priority": 70,
      "once": true,
      "chorus": false,
      "when": { "event": "death_to_boss", "boss": "gorynych", "n_min": 3, "n_max": 3 },
      "after": [],
      "sets": []
    }
  ],
  "boss_lines": [
    {
      "id": "gor_intro_1",
      "boss": "gorynych",
      "moment": "intro",
      "text": "BOSS_GOR_INTRO_1",
      "ru": "С: Ты. С ближнего конца. П: Щита нет. Л: Помним.",
      "once": true,
      "when": { "kills_max": 0, "deaths_max": 0 }
    }
  ]
}
```

Допустимые поля `when`: `event`, `location`, `boss`, `enemy`, `god`, `n_min`, `n_max`,
`title_min`, `title_max`, `ash_min`, `needle`, `kills_min`/`kills_max` (по `save.bosses`),
`deaths_min`/`deaths_max` (по `deaths_by`), `flags_all`, `flags_none`, `every`. Неизвестное поле
при загрузке это ошибка в логе, а не тихий пропуск. `moment` у хозяев: `intro`,
`hero_death`, `defeat`, `choice`. Кроме `lines` и `boss_lines` в файле лежат `god_lines`,
`hero_lines`, `item_lines`, `lore_lines`, `thread_lines`, `gate_lines`: их код пока не читает.

## 3. Мир, который рассказывает сам

### 3.0 Как подаётся найденный лор

Предмет лежит в фоне комнаты и **проявляется в свете оберега** (столп 4: тёмный мир, свет
только у героя). Подошёл, E: одна-две строки внизу экрана и запись в кодексе. Бой не
останавливается. В каждой локации 3 предмета, они стоят в случайных комнатах забега, по
одному за забег, пока все не найдены. **[нужно решение: game-designer и UX, есть ли такая
точка E в забеге; producer, 15 предметов к 1.0]**. Без точки E предметы остаются чистым
декором, а строки уходят в нити Доли. Строки находок: `dialogue/items-and-lore.md` 2.

### 3.1 Топь Кикиморы

**Живое.** Болотные огоньки, которые отлетают от света оберега. Пузыри на дальней воде,
лягушки, что замолкают при бое и снова квакают после. Туман слоями. После победы над
Кикиморой тёплые огни вешек (библия 2.1). Звук: капель, тихое кваканье, далёкий стон.

### 3.2 Тёмный бор

**Живое.** Глаза в дуплах на фоне (библия 2.2), которые моргают, когда герой стоит.
Падает хвоя, мелкие совы на ветках вертят головами за героем. Перед боем с Лихом светлячки
гаснут по одному. Звук: скрип стволов, шорох в корнях, тишина без птиц.

### 3.3 Царство Морены

**Живое.** Снег, который падает очень медленно. Снегири на ледяных ветках (красный акцент
на светлом фоне). Пар от дыхания героя. После победы капель с сосулек (библия 2.3).
Звук: звон льдинок, ветер на одной ноте, далёкий колокольчик.

### 3.4 Калинов мост

Строка про щит меняется на звании «Витязь» и выше: «Тут я его пустил.» (говорит сам герой).
**Живое.** Искры и пепел вверх, огненные рыбы прыгают в Смородине, змеёныши в трещинах на
фоне. Звук: рёв реки, треск углей, скрип цепи Горыныча под мостом.

### 3.5 Кощеево царство

**Живое.** Тишина кладовой. Золото капает с потолка, как воск. Свечи вспыхивают, когда
герой проходит, и гаснут за ним. Моль над сундуками, крысы с монетами в зубах. Прикованные
полоняне на фоне поднимают головы на звук шагов (их меньше с каждой победой, библия 3).
Звук: скрип цепей, звон монет, ровное дыхание где-то за стеной.

### 3.6 Застава

Дым из трубы, Баюн меняет место на печи между заходами, Потап ест, когда в меню не зашли.
После первой победы в игре на крыше гнездо ласточек: весна пришла на заставу.

1. **Голос:** один на персонажа, по `characters.md`. «Мур-р» в 1 строке из 4. У Горыныча спор

   строках главной линии не шутить.
4. **Правило мира:** «смерть ходит только по мосту». Ни одна строка не обещает, что Кощей
   умрёт навсегда раньше настоящего конца.
5. **Миф:** «так говорят на этой заставе». Нет «Русь», «русич», «славянская сила». Потап без
   ушанки, водки и мороза.
6. **Перевод:** без игры слов, которую нельзя передать смыслом. Подстановки именованные.
   Строки длиннее 100 знаков пометить на проверку длины EN.
7. **Формат:** id, NPC, условие (`when`, `after`, `sets`), приоритет, строка. Новые ключи:
   `death_streak`, `win` по `n` побед, флаги выборов. **[нужно решение: lead-programmer]**
